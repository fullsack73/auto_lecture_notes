## 리스크/이슈

- 실제 교정 결과는 사용자가 선택한 LLM 모델 성능에 영향을 받는다.
- macOS 로컬 앱은 ad-hoc 서명이며 Developer ID 서명이나 공증은 하지 않는다.
- Windows/Linux 공개 배포본은 코드 서명되지 않는다.
- workflow는 macOS DMG를 artifact로 검증하지만 공개 Release에는 Windows와
  Linux 산출물만 게시한다.
- GitHub Actions의 Node.js 20 사용 action에 deprecation 경고가 있으나 runner가
  Node.js 24로 강제 실행해 이번 빌드는 성공했다.
