## 리스크 및 대응

- Windows/Linux 배포본은 코드 서명되지 않는다.
- GitHub Actions는 태그 commit에서 각 운영체제 산출물을 다시 빌드하므로
  Release에 게시된 Windows installer checksum은 로컬 빌드와 다를 수 있다.
- 현재 workflow는 macOS DMG를 artifact로 검증하지만 공개 Release 자산에는
  Windows와 Linux 산출물만 포함한다.
- 현재 Windows 머신은 CUDA device를 감지하지만 호환 cuBLAS/cuDNN이 없어
  GPU STT 통합 테스트는 optional test로 분리했다.
- 현재 benchmark reference가 축약본이므로 CER/WER는 후보 간 상대 비교로 해석한다.
