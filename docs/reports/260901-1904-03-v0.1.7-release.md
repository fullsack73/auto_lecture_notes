## 요약

- 녹음 중인 오디오 입력의 peak dBFS를 데스크톱 GUI에 실시간 표시한다.
- PDF/PPTX 자료 용어를 Whisper hotword에서 분리해 prompt 기반 환각 위험을 줄인다.
- Python 패키지와 데스크톱 앱 버전을 `0.1.7`로 갱신한다.

## 변경 범위

- FFmpeg `astats` 기반 실시간 녹음 입력 레벨 수집
- 세션 화면의 녹음 중 전용 입력 레벨 미터
- 세션 제목·과목만 STT hotword로 사용하고 자료 용어는 LLM 정제 문맥으로 제한
- 관련 GUI/runtime/STT 회귀 테스트와 사용자 문서 갱신

## 리스크/이슈

- 실제 입력 레벨은 선택한 장치와 운영체제 녹음 권한에 영향을 받는다.
- macOS 로컬 앱은 ad-hoc 서명이며 Developer ID 서명이나 공증은 하지 않는다.
- Windows/Linux 공개 배포본은 코드 서명되지 않는다.
- workflow는 macOS DMG를 artifact로 검증하지만 공개 Release에는 Windows와
  Linux 산출물만 게시한다.
- GitHub Actions의 Node.js 20 사용 action에 deprecation 경고가 있으나 runner가
  Node.js 24로 강제 실행해 이번 빌드는 성공했다.
