## 리스크 및 대응

- JSON syntax repair도 실패하면 잘못된 노트를 저장하지 않고 원인이 드러나는 오류를 반환한다.
- Windows/Linux 배포본은 코드 서명되지 않는다.
- 태그 push 후 GitHub Actions가 운영체제별 산출물을 같은 commit에서 다시 빌드하므로 Release checksum은 로컬 빌드와 다를 수 있다.
