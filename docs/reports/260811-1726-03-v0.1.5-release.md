# 작업 기록 - v0.1.5 배포

- 일시: 2026-08-11 17:26 (Asia/Seoul)
- 작성자: fullsack73
- 에이전트: Codex
- 작업 유형: 버그 수정/GUI 개선/릴리스

## 요약

- 실행 중인 macOS 앱을 덮어쓰지 않는 안전한 재설치 흐름을 추가했다.
- 설정 변경을 자동 적용하고 설정 화면의 숫자 입력, 콤보 팝업, 폴더 버튼,
  녹음 장치 배치를 정리했다.
- Python 패키지와 데스크톱 앱 버전을 `0.1.5`로 갱신한다.
- macOS, Windows 앱과 Windows installer가 `pyproject.toml`의 버전을 공통으로
  읽도록 하여 플랫폼별 버전 불일치를 방지한다.

## 변경 범위

- 실행 중 설치본 사전 감지와 staging/검증/원자적 교체
- 설치 실패 시 기존 앱 보존 및 패키지 GUI smoke test
- 설정 변경 350ms debounce 자동 저장과 저장 상태 표시
- macOS에서 부자연스러운 숫자 입력 화살표 제거
- 밝은 콤보 팝업, 폴더 버튼 간격, 녹음 장치 행 개선
- 데스크톱 빌드의 단일 버전 원천과 회귀 테스트
- 삭제된 linuxdeploy asset ID를 고정 릴리스 URL과 검증된 SHA-256으로 교체

- `git diff --check` 통과

## 리스크/이슈

- macOS 로컬 앱은 ad-hoc 서명이며 Developer ID 서명이나 공증은 하지 않는다.
- Windows/Linux 배포본은 코드 서명되지 않는다.
- 외부 Ollama 서버가 필요한 통합 테스트는 로컬 서버 부재로 릴리스 검증에서
  제외했다.
